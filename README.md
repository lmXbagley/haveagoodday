# haveagoodday

Сила — в дисциплине и воле: именно они превращают «хочу» в «сделал». Ненависть к себе отнимает силы — лучше беречь их для дела. Мозг умеет меняться, если действовать регулярно. Альтруизм начинается с опоры на себя. Человек способен на многое — главное хотеть по-настоящему и идти вперёд шаг за шагом.
