# ORGANOID SIM

3D-симуляция пространства для проекта с органоидом. X11-окно, софтверный рендер
(без OpenGL), физика опрокидывания робота, TCP API на localhost, звук в центре
комнаты. Всё на C++.

![made by lm](https://img.shields.io/badge/made%20by-lm-black) ![vibecoded](https://img.shields.io/badge/100%25-vibecoded-purple)

## Робот

- плата 10 см × 5 см, высота 3 см
- два колеса по бокам, диаметр 6 см, ось в центре платы
- камера на переднем крае платы
- падает на колёсах вперёд и назад — чистая физика: опрокидывание возникает
  из моментов инерции при торможении/ударе и ограничении угла доски, никаких
  отдельных «функций падения». Упавший робот лежит на грани до сброса (клавиша R)

## Сборка (Debian)

```bash
sudo apt install build-essential libx11-dev pkg-config
make
./organoid-sim            # порт API по умолчанию 4242
./organoid-sim --port 5000
```

Зависимости: только X11. Звук идёт через стандартные утилиты `aplay`/`arecord`
(пакет `alsa-utils`, есть на любом Debian с десктопом).

## Управление

| Действие | Управление |
|---|---|
| вращение камеры | зажать мышь в левой области и вести |
| зум | колесо мыши |
| следить за роботом / свободная камера | `F` |
| ручная езда (тест) | стрелки / WASD |
| стоп моторов | `Пробел` |
| сброс упавшего робота | `R` |
| выход | `Esc` |

## Боковая панель

- **вид с камеры робота** — живой рендер с борта
- **логгер API** — все входящие (`<<`) и исходящие (`>>`) сообщения + события UI (`*`)
- **три сенсорных элемента S1 S2 S3** — пока мышь наведена и зажата, состояние
  передаётся в API (события `PANEL <1..3> DOWN/UP`)
- **аудио**: поле пути к WAV + Enter — загрузить; `REC`/`STOP` — запись с
  микрофона (сохраняется в `recordings/*.wav` и сразу готова к проигрыванию);
  `PLAY`/`STOP` — звук раздаётся в центре комнаты с затуханием по расстоянию
  до робота и стереопанорамой

## API

TCP `127.0.0.1:4242`, текстовые строки, `\n` — разделитель.

Команды (клиент → сим):

| Команда | Описание |
|---|---|
| `MOTOR <left> <right>` | скорость колёс, −100..100 % |
| `STOP` | моторы в 0 |
| `SOUND <path>` | проиграть WAV в центре комнаты |
| `SOUND_STOP` | остановить звук |
| `FRAME` | один кадр камеры: `FRAME <w> <h> <size>\n` + RGB-байты |
| `STREAM <0\|1>` | поток кадров ~15 fps |
| `TELEM <0\|1>` | телеметрия 10 Hz |
| `PANELS` | состояние сенсоров |
| `PING` / `INFO` | проверка / описание протокола |

События (сим → клиент):

| Событие | Описание |
|---|---|
| `PANEL <1..3> <DOWN\|UP>` | нажатие/отпускание сенсора |
| `TELEM <x> <y> <z> <yaw> <pitch> <vl> <vr>` | поза и скорости колёс |
| `FRAME <w> <h> <size>` + бинарные данные | кадр камеры 128×96 RGB |
| `SOUND_DONE <path>` | воспроизведение закончилось |

Проверка в один заход, без клиентского кода:

```bash
printf 'MOTOR 100 100\n' | timeout 1 nc -q0 127.0.0.1 4242
```

Симуляция написана так, чтобы рядом на ПК запускался любой другой код и
взаимодействовал через API. Никаких заглушек: рендер, физика, API и звук —
рабочие.
